SE NÃO ESTIVER APARECENDO
═══════════════════════════════════════════════════════════════════════════════

1. Verifique se vê:
   ✅ Fundo escuro (azul muito escuro quase preto)
   ✅ Navbar no topo (OC + Observa Cultura)
   ✅ Sidebar à esquerda
   ✅ Card de filtros com borda
   ✅ Inputs com fundo escuro
   ✅ Texto branco

2. Se vir tudo em branco/sem estilo:
   → Abra DevTools (F12)
   → Vá para Network
   → Procure por arquivo .css
   → Se tiver 404 ou 0 bytes = problema Tailwind
   → Se tiver 5+ KB = CSS carregou (pode ser cache)

3. Limpe cache:
   → Ctrl + Shift + Delete
   → Ou Ctrl + F5
   → Ou abra em modo incógnito

4. Reinicie dev server:
   → Ctrl + C (no terminal)
   → npm run dev
